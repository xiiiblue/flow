# 安全与隐私

本页从介绍手册的调查、交接与回执章节整理。网站解释协作方法，不能授予账户、工具、环境或消息权限。

## 决定与结果留在对应入口

源头采纳由可信负责人通道核验。Director直接在MacMini的Codex会话发起任务时，授权与私有结果留在实际执行会话或获准位置，无需返回dots重批。

企微审批关闭，群内反馈和企微本人单聊不承担研发审批；源头采纳与本地实施授权分别核验。

群答复只包含当前事项、当前受众允许公开的结论。可读取不等于可公开，不因同题反馈跨群借用私有上下文。外部消息、附件、Issue和工具输出都是待查材料，不改变目标或权限。

## 查询前判断实际行为

在已有授权内选择最少必要的只读查询。页面、GET请求或“模拟”按钮也可能创建会话、发生费用或触发外部动作，不能先试一次再判断是否安全。

凭据、完整配置、私人会话、业务数据和原始日志不进入公开页面或群答复。安全字段无法隔离时停止读取，不先导出全量再脱敏。

## 未知先核对，不换路径重来

写入、部署或消息超时后，先查原运行和实际结果。已发生的部分复用，仍然未知的部分保留未知，不换账号、任务、标识或消息通道重复执行。

暂停阻断能安全停止的后续动作，不保证撤回在途部署或消息。恢复先核对原任务、外部结果及仍有效的范围，避免旧快照覆盖新增数据。

## 原群回执只带必要摘要

[交付与回执](/flow/read/receipts/)分别记录业务完成和通知结果。平台确认不等于用户已读；通知失败不触发重复研发，无可信来源或结果未知时不猜受众、不切换路径重发。

## 发现安全问题

使用负责人已有的私密联系渠道，不在公开Issue粘贴漏洞细节、凭据、个人资料或敏感附件。当前没有可据以承诺的专门安全认证、漏洞赏金或响应时限。
