# 这些说明从哪里来

HiveFlow网站从蜂巢《自动化手册》中选取适合公开的内容，再用常见问题和例子讲给读者。页面下方可以查到手册的版本和取材日期。导出37条数据的对话是教学示例。

## 改一条说明时怎样核对

例如，想知道“修好以后通知哪个群”，先核对项目的正式规则，再看手册是否说清答疑、登记和交付各发给谁。随后修改首页、案例和通知章节，打开手机和电脑上的页面，确认同一件事说法一致。

公开站只保留解释操作所需的信息。真实成员身份、群地址、私有批准记录和原始日志由项目保存。需要在自己的项目运行时，先取得相应的项目权限，核对实际配置。
